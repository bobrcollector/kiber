🔁 Задача: Алгоритм

Условие

Дан фрагмент алгоритма.

Определи результат работы этого фрагмента (чему будут равны K и L) при изначальных K = 32, L = 4.

для X от 0 до 5
нц
если K < L
то L := L − K
иначе K := K / L
все
кц

🔬 Таблица трассировки

Заполни значения K и L после каждого повторения цикла. Можно проверить таблицу или выполнять алгоритм по шагам.

Начальные значения: K = 32, L = 4.

✍️ Ответ

Впиши итоговые значения K и L.

Выполняем цикл шесть раз (X = 0, 1, 2, 3, 4, 5):

X = 0: 32 < 4 — нет, K = 32 / 4 = 8.
X = 1: 8 < 4 — нет, K = 8 / 4 = 2.
X = 2: 2 < 4 — да, L = 4 − 2 = 2.
X = 3: 2 < 2 — нет, K = 2 / 2 = 1.
X = 4: 1 < 2 — да, L = 2 − 1 = 1.
X = 5: 1 < 1 — нет, K = 1 / 1 = 1.

Ответ: K = 1, L = 1.
