🎬 Задача: Билеты в кино

Условие

Внимание! Это задача не на программирование! Но она сложная.

Сегодня премьера нового фильма. Ты приходишь к открытию кассы, а перед тобой в очереди уже стоят n человек. Билеты продают три кассира. Первый кассир обслуживает одного посетителя за 30 секунд, второй — за 50 секунд, третий — за 75 секунд. Очередь за билетами одна, и стоящий в начале очереди отправляется к первому освободившемуся кассиру. Все кассиры начинают работать одновременно. Сколько времени тебе нужно ждать в очереди?

Например, если n = 4, то придётся ждать 50 секунд: первые три человека уйдут к трём кассирам, через 30 секунд освободится первый кассир и к нему уйдёт четвёртый человек из очереди, а через 50 секунд освободится второй кассир, и ты попадёшь к нему.

🔬 Тренажёр: работа кассиров

Каждый прямоугольник — один покупатель у кассира, число в нём — его номер в очереди. Жёлтый — это ты.

Перед тобой человек: n = 4

Для n = 33 и n = 108 тренажёра не хватит — поищи закономерность.

Для маленьких значений n ответ можно получить моделированием процесса вручную. К первому кассиру покупатели будут подходить каждые 30 секунд, то есть через 0, 30, 60, 90, 120, 150, … секунд после начала продажи билетов. Ко второму кассиру — через 0, 50, 100, 150, … секунд. К третьему — через 0, 75, 150, … секунд. Если объединить все эти списки и упорядочить их, то мы получим время ожидания для разных значений n:

0, 0, 0, 30, 50, 60, 75, 90, 100, 120, 150, 150, 150, 180, …

Через 150 секунд освободятся все три кассира, так как 150 — наименьшее общее кратное чисел 30, 50 и 75. За это время кассиры вместе обслужат 5 + 3 + 2 = 10 покупателей. Дальше всё повторяется: при увеличении n на 10 время ожидания увеличивается на 150 секунд.

Поэтому ответ для n = 33 равен 3 · 150 + 30 = 480, а для n = 108 — 10 · 150 + 100 = 1600.

Ответ: 60, 75, 150, 480, 1600.
