🏠 Главная ⬆ К уровню «Старшие (12-14 лет)»

☕ Задача: Чрезвычайно хороший кофе!

Условие

Ограничение по времени: 1 секунда

В кофейне «Дабл Р» постоянные посетители получают каждую n-ю чашку кофе бесплатно. Кроме того, по воскресеньям в этом заведении также можно взять одну чашку кофе бесплатно (она не учитывается при накоплении бонуса). Купер, начиная с некоторого понедельника, в каждый из d дней заходил в это кафе выпить одну чашку кофе. Сколько чашек он выпил бесплатно?

Формат входных данных

Первая строка входных данных содержит натуральное число n (2 ≤ n ≤ 100),
вторая — натуральное число d (1 ≤ d ≤ 109).

Формат выходных данных

Выведите одно неотрицательное целое число — ответ на вопрос задачи.

Примеры

стандартный вводстандартный вывод
3
10		4

В примере каждая третья чашка бесплатна, и Купер заходил в кафе 10 дней подряд. Бесплатные чашки — в среду (3-я чашка в счёт бонуса), субботу (6-я), воскресенье (по акции) и следующую среду (9-я). Всего 4.

🔬 Тренажёр: календарь Купера

обычная чашка (идёт в счёт бонуса) бесплатная по бонусу — каждая n-я бесплатная по воскресенью

✍️ Проверь себя

Что выведет правильная программа на такой ввод?

Посчитай в уме или на листочке.

Идея: моделируем дни

Заведём два счётчика: ans — ответ и current — количество невоскресных дней (чашек, которые идут в счёт бонуса). Пройдём циклом по дням. Мы начинаем с понедельника, поэтому воскресенье — это день, номер которого (с нуля) при делении на 7 даёт остаток 6. В воскресенье чашка бесплатная — увеличиваем ans. В другой день увеличиваем current, и если оно делится на n нацело — эта чашка тоже бесплатная.

n = int(input())
d = int(input())
ans = 0
current = 0
for i in range(d):
    if i % 7 == 6:
        ans += 1
    else:
        current += 1
        if current % n == 0:
            ans += 1
print(ans)

Как сделать быстрее

При d = 109 цикл сделает миллиард шагов и может не уложиться в 1 секунду. Посчитаем то же самое формулой:

воскресений среди d дней — d // 7, невоскресных дней — d − d // 7, а бонусных чашек среди них — каждая n-я, то есть (d − d // 7) // n.

n = int(input())
d = int(input())
sundays = d // 7
print(sundays + (d - sundays) // n)
