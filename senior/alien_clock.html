👽 Задача: Инопланетные часы

Условие

Ограничение по времени: 1 секунда

Сутки на планете другой звёздной системы длятся h часов, а час длится m минут. Цифровое табло робота на поверхности этой планеты показывает время x часов y минут. Через сколько минут цифровое табло будет показывать время, для которого сумма чисел, обозначающих часы и минуты, будет равна текущей сумме чисел на часах?

Формат входных данных

Программа получает на вход четыре целых неотрицательных числа h, m, x и y, записанные в отдельных строках — длительность суток в часах, длительность часа в минутах, часы и минуты, которые отображаются на цифровом табло робота (0 ≤ x < h, 0 ≤ y < m). Все числа не превосходят 108. Гарантируется, что h < m.

Формат выходных данных

Программа должна вывести одно целое число — через сколько минут цифровое табло будет показывать время, когда сумма значений часов и минут будет равна аналогичной сумме в данный момент.

Ответ может превышать возможное значение 32-битной целочисленной переменной, поэтому в C++ нужен тип long long, в Java и C# — long. В Python целые числа могут быть любой длины.

Идея

Искомое время может выпасть либо на текущие сутки, либо уже после полуночи.

Текущие сутки. Внутри часа минуты только растут, и сумма растёт вместе с ними. Значит, ближайший шанс — следующий час: часы увеличатся на 1, а минуты уменьшатся на 1, то есть время (x+1):(y−1). До него ровно m − 1 минут. Так можно, только если x + 1 < h (следующий час ещё в этих сутках) и y > 0 (минуты не станут отрицательными). В более поздние часы минут понадобится ещё меньше — значит, если не подошёл следующий час, то в текущих сутках ответа нет.

Следующие сутки. Количество минут = время до конца текущих суток + время от начала суток до искомого момента. Сумму S = x + y нужно разложить на часы и минуты так, чтобы время было как можно раньше: минуты делаем как можно больше, но не больше m − 1, а остаток отдаём часам. Получаем часы a = max(0, S − (m − 1)) и минуты b = S − a.

h = int(input())
m = int(input())
x = int(input())
y = int(input())

if x + 1 < h and y > 0:
    # Следующий час, на минуту меньше
    print(m - 1)
else:
    s = x + y
    # Самое раннее время в следующих сутках с суммой s
    a = max(0, s - (m - 1))
    b = s - a
    to_midnight = h * m - (x * m + y)
    print(to_midnight + a * m + b)
