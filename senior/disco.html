🪩 Задача: Дискотека

Условие

Ограничение по времени: 0.5 секунд

На дискотеке в ряд стоят три прожектора, которые поочерёдно светят в следующем порядке: левый, средний, правый, средний, левый, средний, правый, средний и т.д. (слева направо, затем налево, опять направо, ...). Каждый прожектор горит в течение одной секунды.

Известно, что лампа левого прожектора имеет ресурс A секунд горения, среднего — B секунд, правого — C секунд. Определите, сколько времени сможет продолжаться этот процесс горения прожекторов.

Формат входных данных

Программа получает на вход три целых неотрицательных числа A, B, C — время горения левого, среднего, правого прожектора.

Формат выходных данных

Программа должна вывести одно целое число.

Пример

стандартный вводстандартный вывод
3
3
3		7

🔬 Тренажёр: включаем прожекторы

✍️ Проверь себя

Что выведет правильная программа на такой ввод?

Посчитай в уме или на листочке.

Идея

Порядок повторяется каждые 4 секунды: Л С П С | Л С П С | … Посмотрим на каждый прожектор отдельно, как будто ресурс остальных бесконечен.

Левый горит на 1-й, 5-й, 9-й, … секундах — раз в 4 секунды. Если его ресурс равен a, то после a-го включения пройдёт ещё 3 секунды (С, П, С), и только потом он понадобится снова. Прожекторы смогут гореть 4a секунд.

Средний горит на каждой чётной секунде: 2, 4, 6, … Его b-е включение — на секунде 2b, следующая секунда (2b + 1) — без него. Время горения будет 2b + 1.

Правый горит на 3-й, 7-й, 11-й, … секундах. Его c-е включение — на секунде 4c − 1, затем ещё 3 секунды (С, Л, С). Ответ будет 4c + 2.

Процесс остановится, как только сгорит первая из ламп, поэтому нужно вывести наименьшее из этих трёх чисел.

a = int(input())
b = int(input())
c = int(input())

print(min(4 * a, 2 * b + 1, 4 * c + 2))
