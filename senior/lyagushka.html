🧮 Как посчитать время?

Давай выведем формулу вместе с ребенком:

1. Начальное расстояние:
Лягушка на 1, Кузнечик на N.
Расстояние = N - 1
2. Скорость сближения:
Лягушка прыгает на 3, Кузнечик на 2.
За 1 секунду они сближаются на: 3 + 2 = 5 клеток.
3. Итоговая формула (целочисленное деление):
Время = (Расстояние + 4) // 5
Время = (N - 1 + 4) // 5
Прибавляем 4, чтобы округлить вверх при делении на 5.
Пример для N=9: (9 - 1 + 4) // 5 = 12 // 5 = 2 секунды.

💻 Решение на Python


# Считываем длину дорожки
n = int(input())

# Если дорожка короче 4 клеток,
# они не смогут встретиться
if n < 4:
    print(-1)
else:
    # Формула: (n - 1 + 4) // 5
    print((n - 1 + 4) // 5)
