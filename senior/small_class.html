🏫 Задача: Маленький класс

Условие

Ограничение по времени: 1 секунда

В классе N учеников. Учитель опрашивает сначала всех учащихся с нечётными номерами (1, 3, 5, ...), затем всех с чётными номерами (2, 4, 6, ...). Андрей, имеющий номер K по журналу, хочет узнать, какой по порядку вопрос достанется ему. Напишите программу, вычисляющую номер вопроса по данным N и K.

Формат входных данных

Вводятся два целых числа N и K, каждое в отдельной строке (1 ≤ N ≤ 1000, 1 ≤ K ≤ N).

Формат выходных данных

Выведите одно целое число — номер вопроса, который достанется Андрею.

Примеры

стандартный вводстандартный вывод
10
7		4
10
6		8

🔬 Тренажёр: в каком порядке спрашивает учитель

Сверху — номер вопроса, снизу — номер ученика по журналу. ■ нечётные ■ чётные ■ Андрей

✍️ Проверь себя

Что выведет правильная программа на такой ввод?

Посчитай в уме или на листочке.

Идея

Если K — нечётное, то Андрей окажется в первой половине опрошенных, поэтому ответом будет порядковый номер числа K среди всех нечётных чисел. Его можно найти по формуле (K + 1) // 2 (где // — операция целочисленного деления).

Если K — чётное, то нужно определить, какое это по порядку чётное число (K // 2), а также добавить количество нечётных чисел от 1 до N ((N + 1) // 2) — их всех спросят раньше. Получится формула K // 2 + (N + 1) // 2.

n = int(input())
k = int(input())

if k % 2 != 0:
    # нечётный номер — спросят в первой половине
    print((k + 1) // 2)
else:
    # чётный — сначала спросят всех нечётных
    print(k // 2 + (n + 1) // 2)
