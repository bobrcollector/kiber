📺 Задача: Рекламная пауза

Условие

Ограничение по времени: 0.5 секунд

Кибер Мишка включил в онлайн-кинотеатре новый фильм «Матрица». После каждых a минут показа фильма вставляется реклама длиной b минут. Но если в момент планируемого начала рекламного блока фильм завершается, то рекламу не показывают. Фильм без рекламы длится n минут. Сколько времени займёт показ всего фильма вместе с рекламой?

Формат входных данных

Первая строка содержит одно целое число a (1 ≤ a ≤ 109) — длительность блока фильма между рекламами.
Вторая строка содержит одно целое число b (1 ≤ b ≤ 109) — длительность одного рекламного блока.
Третья строка содержит одно целое число n (1 ≤ n ≤ 109) — длительность оригинала фильма без рекламы.

Формат выходных данных

Выведите одно целое число — длительность фильма с рекламой.

Ответ может превышать возможное значение 32-битной целочисленной переменной, поэтому в C++ нужен тип long long, в Java и C# — long. В Python целые числа могут быть любой длины.

Идея

К длине фильма нужно добавить количество рекламных пауз, умноженное на продолжительность одной паузы b. Рекламные паузы вставляются через каждые a минут, поэтому для подсчёта их числа нужно поделить n нацело на a.

Но если n делится на a (остаток от деления n % a равен 0), то время последней рекламной паузы совпадёт с окончанием фильма — реклама показываться не будет, и число пауз нужно уменьшить на 1.

# Считываем данные
a = int(input())
b = int(input())
n = int(input())

# Сколько раз фильм «доходит» до рекламы
n_pauses = n // a
# Реклама в самом конце фильма не показывается
if n % a == 0:
    n_pauses -= 1

print(n + n_pauses * b)
